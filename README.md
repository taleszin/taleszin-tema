# Taleszin Tema

Módulo Xposed que troca o azul Holo do KitKat pelo laranja #FF7A1A da Taleszin OS em todos os apps (9 cores + ~180 drawables). Desliga criando `/data/local/tmp/m7s-tema.off`.

Build: extraia `framework-res.apk` e `SystemUI.apk` do seu próprio firmware para `stock/` (não versionado: é proprietário) e rode `./build.sh`.

Parte da [Taleszin OS](https://github.com/taleszin/taleszin-os), ROM autoral para o tablet Multilaser M7s Dual Core (RK3026, Android 4.4). Licença MIT.
